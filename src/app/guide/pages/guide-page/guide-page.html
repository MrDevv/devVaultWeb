DevVault API Documentación

Introducción

Una vez que tienes tu perfil cargado en DevVault, el siguiente paso es conectarlo a tu portafolio. Para eso existe esta API: un conjunto de 4 endpoints que puedes consultar desde cualquier frontend usando tu API KEY personal, que generas luego de registrarte.

Esta guía cubre todo lo que necesitas para hacer tus primeras peticiones: cómo incluir tu KEY en los headers, qué devuelve cada endpoint y qué esperar en la respuesta.

Autorización de dominio

Por seguridad, cada API Key está asociada a un dominio autorizado. La API solo acepta peticiones provenientes de ese origen, por lo que un dominio no configurado o inactivo inhabilita esta seguridad.

Entornos de desarrollo (localhost)

Si vas a implementar o probar un endpoint en desarrollo (http://localhost:3000), la validación del dominio debe estar deshabilitada o pendiente de configuración. De lo contrario la API rechazará la solicitud por CORS aunque envíes correctamente tu API Key.

Cómo configurarlo:

  • Ve a Administrar API → sección Dominio autorizado.
  • Para desarrollo: deja el dominio en Sin configurar o desactiva el switch (estado Inactivo).
  • Al desplegar a producción, registra tu dominio (con protocolo, ej. https://miportafolio.com) o actívalo.
